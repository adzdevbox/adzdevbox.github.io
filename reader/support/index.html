Reader Support

Support for Reader, Reader Dev, privacy questions, and data requests.

Support contact

Email privacy@adz-dev-coding.pl for Reader or Reader Dev support.

Privacy and data requests

Privacy questions and data requests can be sent to privacy@adz-dev-coding.pl.

What to include

  • app name: Reader or Reader Dev;
  • package identity if relevant: com.adzdevbox.mdredv2android or com.adzdevbox.mdredv2android.dev;
  • app version if available;
  • Android version and device model;
  • a short description of what happened and what you expected;
  • steps to reproduce the issue if possible.

What not to include

Please do not include tokens, passwords, private documents, provider payloads, sensitive workspace names, screenshots containing secrets, or private repository content in support messages unless specifically requested for a narrow private diagnosis.

Basic troubleshooting

  • Restart Reader and try the action again.
  • Confirm whether the issue happens in Reader, Reader Dev, or both.
  • Check that the file is a supported text or Markdown document.
  • Check that the file or folder is still available through Android's document picker.
  • For Google Drive or GitHub connector issues, check network access and reconnect the account or token if needed.
  • Clear app cache or data only if you understand local app data may be affected. Try exporting a copy before clearing app data or reinstalling.
  • When reporting a repeatable issue, include the shortest set of steps that reproduces it.

Account and access

Reader local document use does not require a Reader account.

Optional Google Drive or GitHub features require your own third-party account or access token with the corresponding service.

Optional connectors

Google Drive and GitHub connector features are optional. If a problem is specific to a connector, include which connector you used and the action you were trying to perform, without sending private files or secrets.

Privacy Policy

The Reader Privacy Policy is available at https://adz-dev-coding.pl/reader/privacy/.
